# Teaching Materials for Schools

A comprehensive collection of educational resources and study materials designed for school students. This repository aims to provide clear, accessible, and structured notes to help students grasp fundamental academic concepts.

## 🌟 Features
- **Structured Content**: Materials are neatly organized by subject and topic.
- **Multiple Formats**: Resources are provided in both `.docx` and `.pdf` formats for easy editing and printing.
- **Comprehensive Coverage**: Includes in-depth notes on critical topics essential for school examinations.

## 📖 Available Subjects

### Mathematics
The `Math` directory contains detailed notes and exercises for the following topics:
- Arithmetic
- Polynomials
- Pair of Linear Equations in Two Variables
- Quadratic Equations
- Coordinate Geometry
- Triangles & Circles (including Areas and Constructions)
- Trigonometry & Its Applications
- Surface Area and Volume
- Statistics & Probability
- Irrational Numbers

## 🚀 Getting Started
You can directly download the `.pdf` files for reading or use the `.docx` files if you wish to edit or add your own notes. Simply browse the folders and click on the file you want to view or download.
